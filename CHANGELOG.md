# Changelog

## [0.4.1] - 2026-10-19

Initial public experimental version.

- Publish `context-aware-ui` as a lean, platform-independent Agent Skill.
- Preserve context, emotional tone, information density, safety, aesthetics, and evidence boundaries as separate design judgments.
- Package `SKILL.md` plus three on-demand reference documents.
- Remove web-specific tooling and runtime dependencies.
- Add documentation and MIT license.

**Validation:** package structure and reference links have been reviewed. Controlled tests of model behavior and human UX outcomes are still pending.
