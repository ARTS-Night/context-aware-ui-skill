# 環境適応と根拠の境界

原理は共有できても、**寸法・入力・表示距離・時間・感覚モダリティの最適値は共通ではない**。実装先の公式ガイド、利用可能な既存コンポーネントと実機条件を確認する。

| 対象 | 確認すべき具体的条件 | そのまま持ち込まないもの |
|---|---|---|
| Web/SPA | 動的幅、ブラウザー、入力、読み込み、Webアクセシビリティ | PC横長固定、静的CSS検査だけで動作合格 |
| デスクトップGUI | ウィンドウ、キーボード、長時間の高密度作業、OS慣習 | 巨大カード・タップ用サイズの無条件移植 |
| スマートフォン | タッチ、片手操作、キーボード出現、狭さ、ジェスチャ | PC画面の単純縮小 |
| VR/AR | 視認距離、角度、奥行き、視線/手/コントローラー、疲労 | CSS px、hover、2Dスクロールの直輸入 |
| ゲーム/HUD | 行動時の注意、表示のタイミング、コントローラー、世界観 | 常時すべての情報を見せること |
| 組込み/公共端末 | 低性能、照明、緊急時の操作、共有端末と支援 | 常時ネット接続や精密操作 |
| 音声/触覚UI | 順序、短い確認、復唱、訂正、応答遅延 | 色・余白・文字階層を必須にすること |

## 根拠は何を支えるか

- **規範:** [WCAG 2.2](https://www.w3.org/TR/WCAG22/) はWeb向け。コントラストなどの数値は条件と例外ごとに判断し、他環境へ合格値としてそのまま適用しない。
- **美観の研究:** [Lavie & Tractinsky (2004)](https://doi.org/10.1016/j.ijhcs.2003.09.002) は秩序/明快さと表現/独創性というWebサイトの美観の側面を研究。[Tuch et al. (2012)](https://doi.org/10.1016/j.ijhcs.2012.06.003) は第一印象と複雑性・典型性の関係を研究。いずれもあらゆるデバイスや長期操作への万能則ではない。
- **美観と性能:** [Schlamann et al. (2026)](https://doi.org/10.1080/10447318.2026.2664081) は平均的な正の関連を報告するが、異質性が大きい。美しさが必ず操作性能を高めるという因果保証ではない。
- **設計上の仮説:** 「業務UIでは控えめ」「創作UIでは派手」などは固定法則にしない。1件のSkillあり/なし比較から普遍的な結論は出せない。

プラットフォーム固有の知識が不明なら、推測で正解の寸法・操作方式を断言しない。Web・デスクトップ・VRなどで評価方法を切り替える。UIの見た目が整っていてもユーザーが快適であるという科学的証明にはならない。
